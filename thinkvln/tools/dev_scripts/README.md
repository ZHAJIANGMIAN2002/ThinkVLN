# Development Scripts

This folder contains the original development versions of data generation scripts. These scripts were used during the research and prototyping phase.

**For production use, please use the production-ready versions in `thinkvln.data.generation` instead.**

## Contents

- `cot_generation.py` - Original CoT generation script
- `subtask_determination.py` - Original subtask determination script
- `subtask_split.py` - Original subtask splitting script

## Production vs Development

| Development (this folder) | Production (`data/generation/`) |
|---------------------------|----------------------------------|
| Prototyping and experiments | Production-ready, optimized |
| May have hardcoded paths | Configurable parameters |
| Research-oriented | Deployment-oriented |

These scripts are kept for reference and reproducing research results.
